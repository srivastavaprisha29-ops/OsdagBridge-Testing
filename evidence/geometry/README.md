# Desktop geometry and OSI boundary checks

The nine cases in the boundary register exercised desktop line-edit signals and the OSI validation gate on the pinned upstream dev revision. The harness recorded the warning text and compared the resulting widget value with the Input Dictionary. It intercepted modal warnings so the test could continue. The OSI check called the same validator used by Load Input, without opening the file picker.

Both advertised span endpoints (20 m and 45 m) were accepted. Out-of-range span values, including zero and negative values, produced warnings and were clamped in the GUI. The OSI validator rejected the original invalid values. For carriageway width, 4.25 m was accepted without a median and corrected to 7.5 m with a median. A 23.61 m width was corrected to 23.6 m.

These cases exercise input validation. The baseline remains the completed desktop design run. Full design runs at the span endpoints and further girder, deck, support and load variations remain pending.
